# S0040 — Breadcrumb "Principal / Dashboard" repete o título
- **Tela:** AmploPay › App › Dashboard · **Versão analisada:** produção (conta nova, 2026-11-10) · recriada em v1
- **Autor:** Claude Code (avaliação heurística) · **Data:** 2026-11-10
- **Origem:** print enviado pelo usuário (app.amplopay.com/panel/dashboard)
- **Severidade:** 1 de 4 · **Base:** H8 Estética minimalista · H1 Visibilidade do status

## Sugestão
Trocar o breadcrumb por um subtítulo que diz o período ativo ("Resumo das suas vendas nos últimos 7 dias.") e manter o breadcrumb só nas páginas internas.

## Motivo
Em página de primeiro nível o breadcrumb não orienta; o subtítulo com o período informa o que os números significam.

## Alternativas
- A. Subtítulo com o período (recomendada)
- B. Só remover o breadcrumb
- C. Breadcrumb só em páginas internas (combina com A)
