# S0002 — Colapsar cards de moedas sem saldo
- **Tela:** Finanças › Saques · **Versão analisada:** v1
- **Autor:** Claude Code (levantado na criação da v1) · **Data:** 2026-11-10
- **Origem:** PR #1

## Sugestão
Os cards de MXN e COP zerados ocupam o mesmo espaço do BRL. Avaliar mostrá-los compactos (uma linha, com as ações) quando não houver saldo nem movimentação.

## Motivo
A maior parte dos lojistas usa só BRL; os cards vazios empurram a tabela de saques para baixo.
